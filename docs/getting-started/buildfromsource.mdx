# Build from Source (Advanced)
:::warning
This method is not recommended for most users. It is intended for advanced users who are familiar with managing their own server infrastructure.

Refer to [Configuring Databases](/extending-sinerr/database-config#postgresql-options) for details on how to configure your database.
:::

### Prerequisites
    - [Node.js 22.x](https://nodejs.org/en/download/)
    - [Pnpm 10.x](https://pnpm.io/installation)
    - [Git](https://git-scm.com/downloads)

## Unix (Linux, macOS)
### Installation
1. Assuming you want the working directory to be `/opt/sinerr`, create the directory and navigate to it:
```bash
sudo mkdir -p /opt/sinerr && cd /opt/sinerr
```
2. Clone the Sinerr repository and checkout the main branch:
```bash
git clone https://github.com/thelinyue/sinerr.git .
git checkout main
```
3. Install the dependencies:
```bash
CYPRESS_INSTALL_BINARY=0 pnpm install --frozen-lockfile
```
4. Build the project:
```bash
pnpm build
```
5. Start Sinerr:
```bash
pnpm start
```

:::info
You can now access Sinerr by visiting `http://localhost:5055` in your web browser.
:::

#### Extending the installation
<Tabs groupId="unix-extensions" queryString>
  <TabItem value="linux" label="Linux">
To run sinerr as a systemd service:
1. create the environment file at `/etc/linyue/sinerr.conf`:
```bash
## Sinerr's default port is 5055, if you want to use both, change this.
## specify on which port to listen
PORT=5055

## specify on which interface to listen, by default sinerr listens on all interfaces
#HOST=127.0.0.1

## Uncomment if you want to force Node.js to resolve IPv4 before IPv6 (advanced users only)
# FORCE_IPV4_FIRST=true
```
2. Then run the following commands:
```bash
which node
```
Copy the path to node, it should be something like `/usr/bin/node`.

3. Create the systemd service file at `/etc/systemd/system/sinerr.service`, using either `sudo systemctl edit sinerr` or `sudo nano /etc/systemd/system/sinerr.service`:
```bash
[Unit]
Description=Sinerr Service
Wants=network-online.target
After=network-online.target

[Service]
EnvironmentFile=/etc/linyue/sinerr.conf
Environment=NODE_ENV=production
Type=exec
Restart=on-failure
WorkingDirectory=/opt/sinerr
ExecStart=/usr/bin/node dist/index.js

[Install]
WantedBy=multi-user.target
```
:::note
If you are using a different path to node, replace `/usr/bin/node` with the path to node.
:::

4. Enable and start the service:
```bash
sudo systemctl enable sinerr
sudo systemctl start sinerr
```
  </TabItem>
  <TabItem value="macos" label="macOS">
To run sinerr as a launchd service:
1. Find the path to node:
```bash
which node
```
Copy the path to node, it should be something like `/usr/local/bin/node`.

2. Create a launchd plist file at `~/Library/LaunchAgents/com.sinerr.plist`:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.sinerr</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/local/bin/node</string>
    <string>/opt/sinerr/dist/index.js</string>
  </array>
  <key>WorkingDirectory</key>
  <string>/opt/sinerr</string>
  <key>EnvironmentVariables</key>
  <dict>
    <key>NODE_ENV</key>
    <string>production</string>
    <key>PORT</key>
    <string>5055</string>
  </dict>
  <key>RunAtLoad</key>
  <true/>
  <key>KeepAlive</key>
  <true/>
</dict>
</plist>
```
:::note
If you are using a different path to node, replace `/usr/local/bin/node` with the path to node.
:::
3. Load the service:
```bash
sudo launchctl load ~/Library/LaunchAgents/com.sinerr.plist
```
3. Start the service:
```bash
sudo launchctl start com.sinerr
```
4. To ensure the service starts on boot, run the following command:
```bash
sudo lauchctl load
```

  <TabItem value="pm2" label="PM2">
To run sinerr as a PM2 service:
1. Install PM2:
```bash
npm install -g pm2
```
2. Start sinerr with PM2:
```bash
NODE_ENV=production pm2 start dist/index.js --name sinerr
```
3. Save the process list:
```bash
pm2 save
```
4. Ensure PM2 starts on boot:
```bash
pm2 startup
```
**Managing the service**
- To start the service:
```powershell
pm2 start sinerr
```
- To stop the service:
```powershell
pm2 stop sinerr
```
- To restart the service:
```powershell
pm2 restart sinerr
```
- To view the logs:
```powershell
pm2 logs sinerr
```
- To view the status:
```powershell
pm2 status sinerr
```

## Windows
### Installation
1. Assuming you want the working directory to be `C:\sinerr`, create the directory and navigate to it:
```powershell
mkdir C:\sinerr
cd C:\sinerr
```
2. Clone the Sinerr repository and checkout the main branch:
```powershell
git clone https://github.com/thelinyue/sinerr.git .
git checkout main
```
3. Install the dependencies:
```powershell
npm install -g win-node-env
$env:CYPRESS_INSTALL_BINARY = 0; pnpm install --frozen-lockfile
```
4. Build the project:
```powershell
pnpm build
```
5. Start Sinerr:
```powershell
pnpm start
```

:::tip
You can add the environment variables to a `.env` file in the Sinerr directory.
:::

:::info
You can now access Sinerr by visiting `http://localhost:5055` in your web browser.
:::

#### Extending the installation
<Tabs groupId="windows-extensions" queryString>
  <TabItem value="task-scheduler" label="Task Scheduler">
To run sinerr as a bat script:
1. Create a file named `start-sinerr.bat` in the sinerr directory:
```batch
@echo off
set PORT=5055
set NODE_ENV=production
node dist/index.js
```
2. Create a task in Task Scheduler:
- Open Task Scheduler
- Click on "Create Basic Task"
- Name the task "Sinerr"
- Set the trigger to "When the computer starts"
- Set the action to "Start a program"
- Set the program/script to the path of the `start-sinerr.bat` file
- Set the "Start in" to the sinerr directory.
- Click "Finish"

Now, Sinerr will start when the computer boots up in the background.
  </TabItem>

  <TabItem value="nssm" label="NSSM">
To run sinerr as a service:
1. Download the [Non-Sucking Service Manager](https://nssm.cc/download)
2. Install NSSM:
```powershell
nssm install Sinerr "C:\Program Files\nodejs\node.exe" "C:\sinerr\dist\index.js"
nssm set Sinerr AppDirectory "C:\sinerr"
nssm set Sinerr AppEnvironmentExtra NODE_ENV=production
```
3. Start the service:
```powershell
nssm start Sinerr
```
4. To ensure the service starts on boot, run the following command:
```powershell
nssm set Sinerr Start SERVICE_AUTO_START
```

### Updating
To update Sinerr, navigate to the Sinerr directory and run the following commands:
```bash
git pull
```
Then, follow the steps in the installation section to rebuild and restart Sinerr.
