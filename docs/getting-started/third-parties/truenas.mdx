:::warning
Third-party installation methods are maintained by the community. The Sinerr team is not responsible for these packages.
:::

:::warning
This method is not recommended for most users. It is intended for advanced users who are using TrueNAS distribution.
:::

## Installation

Go to the 'Apps' menu, click the 'Discover Apps' button in the top right, search for 'Sinerr' in the search bar, and install the app.
