# Kubernetes
:::warning
This method is not recommended for most users. It is intended for advanced users who are using Kubernetes.
:::

:::info
All official Sinerr charts are cryptographically signed and include a verified [Software Bill of Materials (SBOM)](https://cyclonedx.org/).

To confirm that the chart you are using is authentic and unmodified, please refer to the [Verifying Signed Artifacts](/using-sinerr/advanced/verifying-signed-artifacts#verifying-signed-helm-charts) guide.
:::

## Installation
```console
helm install sinerr oci://ghcr.io/thelinyue/sinerr/sinerr-chart
```
Helm values can be found in the Sinerr repository under [charts/sinerr-chart/README.md](https://github.com/thelinyue/sinerr/tree/develop/charts/sinerr-chart).

Verify the signature with [cosign](https://docs.sigstore.dev/cosign/system_config/installation/) (replace [tag], with the TAG you want to verify) :
```console
cosign verify ghcr.io/thelinyue/sinerr/sinerr-chart:[tag] --certificate-identity=https://github.com/thelinyue/sinerr/.github/workflows/helm.yml@refs/heads/main --certificate-oidc-issuer=https://token.actions.githubusercontent.com
```
